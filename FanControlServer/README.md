# FanControlServer

FanTune 是一款面向 NAS 与 x86 主板的智能风扇与温度管理软件：温控曲线、多风扇管理、实时硬件监控。基于开源项目 [FanControlServer](https://github.com/guan-ry/FanControlServerApp) 品牌定制，支持 IT87/NCT6775 等通用 Super I/O 风扇芯片（威联通等厂商的 NAS 大量采用此类芯片，fnOS 已内置相关驱动，开箱即用）；少数采用 IT8528 EC 的机型内置 [qnap8528 驱动](https://github.com/iamiao/8528) 随包自动安装。适配飞牛 OS（fnOS）应用中心，本仓库即 FnDepot 第三方源（仓库模式或 JSON 直链均可添加），可在商店一键安装。

- 主页：https://github.com/kitblue/FanControlServerApp
- 问题反馈：https://github.com/kitblue/FanControlServerApp/issues
